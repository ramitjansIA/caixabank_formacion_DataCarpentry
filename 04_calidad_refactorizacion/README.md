# Calidad de código y refactorización

Material docente para la sesión práctica de **Calidad de código y refactorización** del curso *Python Profesional para Analítica Avanzada*.

## Contenido

- `notebooks/notebook_alumnado.ipynb`: recorrido guiado y ejercicios progresivos para el alumnado.
- `notebooks/notebook_solucion.ipynb`: versión docente con las soluciones.
- `notebooks/guion_sesion.md`: secuencia de clase y tiempos orientativos.
- `presentacion/calidad_refactorizacion.html`: presentación lista para abrir en el navegador.
- `presentacion/calidad_refactorizacion.qmd`: fuente Quarto de la presentación.

## Uso recomendado

1. Abrir `presentacion/calidad_refactorizacion.html` en un navegador.
2. Realizar el recorrido inicial del notebook de alumnado de forma guiada.
3. Dejar la práctica y los retos para trabajo individual o por parejas.
4. Usar la versión de soluciones solo para la corrección y discusión final.

La carpeta `presentacion` contiene el HTML, sus recursos y los ficheros auxiliares necesarios para mantener la presentación portable.
